# Drlucaa Vst

## How do I install these formulae?

`brew install drlucaa/vst/<formula>`

Or `brew tap drlucaa/vst` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "drlucaa/vst"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
